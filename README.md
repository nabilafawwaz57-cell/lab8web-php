## 🌷 1. Tentang Praktikum

Praktikum 7 membahas tentang pemrograman server-side menggunakan bahasa pemrograman PHP. Pada praktikum ini, saya mempelajari bagaimana PHP bekerja untuk menerima, mengolah, dan menampilkan data yang dikirimkan oleh pengguna melalui halaman web.

Materi yang dipelajari dimulai dari pengenalan PHP, penggunaan variabel, operator, percabangan, perulangan, array, function, hingga pengolahan data menggunakan form dengan metode GET dan POST.

## 🧁 6. Mini Project

### Aplikasi Formulir Data Mahasiswa

Pada mini project ini, saya membuat aplikasi formulir data mahasiswa menggunakan PHP dengan metode POST.

Formulir memiliki beberapa bagian input, yaitu:

- Nama mahasiswa.
- NIM.
- Program studi.
- Semester.
- Email.

Aplikasi melakukan validasi terhadap data yang dimasukkan. Jika data sudah sesuai, sistem akan menampilkan informasi mahasiswa. Jika terdapat kesalahan, sistem akan menampilkan pesan kesalahan.

Mini project ini juga menerapkan `htmlspecialchars()` untuk membantu mencegah input pengguna ditampilkan sebagai HTML yang tidak diinginkan.

## 🚀 8. Cara Menjalankan Program

Berikut langkah-langkah menjalankan program PHP:

1. Pastikan XAMPP dan PHP sudah terpasang.
2. Buka folder proyek `praktikum-8-web-php` menggunakan Visual Studio Code.
3. Pilih menu Terminal, kemudian New Terminal.
4. Jalankan perintah berikut untuk memulai server PHP:

```powershell
& "C:\xampp\php\php.exe" -S localhost:8000
```

5. Tunggu sampai server berhasil dijalankan.
6. Buka Google Chrome.
7. Masukkan alamat berikut:

```text
http://localhost:8000
```

8. Untuk membuka latihan tertentu, tambahkan nama file pada alamat browser.

Contoh:

```text
http://localhost:8000/latihan2.php
```

**Catatan:** Terminal harus tetap terbuka selama server PHP digunakan.
